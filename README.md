# PY-ML 数据转换插件

本地目录：`F:\桌面\程序\PY-ML-support`。
代码仓库：https://github.com/hexiovo/PY-ML_support_trans 。

## 当前状态

需要批处理，按其它项目逐个接入转换器，转换后的表格用于导入 PY-ML。
当前阶段只准备主程序插件接口，**尚未包含实际转换器和转换 EXE**。
直接选择本仓库目录时，主程序的数据转换入口仍为灰色。
原始数据和转换结果保留在本地，不上传到代码仓库。

## 主程序入口

菜单顺序：文件 → 分析 → 插件 → 帮助。

- 插件 → 数据转换：检测到兼容启动文件后启用，默认灰色。
- 插件 → 设置：始终可用，选择插件目录，可选插件环境的 Python 程序。
- 启动和展开插件菜单时重新检测，删除或移动插件后入口恢复灰色。
- 设置单独保存为用户设置目录中的 `plugins.json`，不进入训练配置。

插件通过外部进程启动，插件依赖不加入主程序基础依赖。
未来发布自带依赖的 EXE 时无需用户安装 Python；源码插件在冻结主程序中
需要选择外部 Python 环境，不能用主程序 EXE 代替 Python。

## 插件接口 v1

插件发布目录包含 `pyml-plugin.json`，格式如下。这里是接口示例，只有
真实启动文件交付后才创建正式清单，不用空清单宣称插件可用。

```json
{
  "schema_version": 1,
  "id": "data-conversion",
  "name": "数据转换",
  "version": "0.1.0",
  "entrypoint": {
    "kind": "executable",
    "path": "PYML-DataConversion.exe"
  }
}
```

Python 版本的 `entrypoint` 可以是
`{"kind": "python", "path": "launch.py"}`。使用所选 Python 程序加上
`-X utf8` 和脚本绝对路径启动。源码版主程序未填写 Python 时使用自身 Python；
冻结主程序必须选择插件环境的 `python.exe` 或 `pythonw.exe`。

启动文件使用发布目录内相对路径，不能指向目录外。
检测只读取清单并检查启动文件，不执行插件或安装依赖。
运行时以插件目录为工作目录，通过参数列表启动，不拼接 shell 命令。
目前转换结果通过 PY-ML 现有“选择训练数据”入口导入；具体批处理规则
和导出布局在提供对应项目后逐项确认。
